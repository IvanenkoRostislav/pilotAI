# Перехід на текстове бронювання — 18 листопада 2026

## Поточна поведінка

Агент сам починає бронювання після `/book`, читає лише текстові повідомлення та
відповідає лише текстом. Навіть прохання надіслати голосове не вмикає озвучення.
На вкладення надходить текстове прохання написати повідомлення; жодне аудіо не
завантажується й не передається AI. Текст із попереднім переглядом посилання
продовжує оброблятися як текст. Основна модель в `.env` — `gemini-3.1-flash-lite`,
резервна — `gemini-3.5-flash-lite`. `TARGET_USERNAME=@nazar699` не змінено.

## Зміни

- `telegram/messanging.ts`: прибрано голосовий транспорт, STT/TTS, аудіочергу та
  перемикання формату; додано відповідь про підтримку лише тексту.
- `telegram/client.ts`, `config/env.ts`: вилучено створення голосових сервісів
  і їхні налаштування. FFmpeg/System.Speech більше не потрібні.
- `agent/agent.ts`, `agent/prompt.ts`, `ai/system-prompt.ts`: текстовий контракт,
  без поля вибору голосової відповіді; збережено факти, стани та захист від витоків.
- `logger/logger.ts`: записи TEXT/MEDIA без окремих голосових транскрипцій.
- Вилучено AI/Telegram-модулі голосу, конвертер Opus, Windows TTS, їхні тести,
  `scripts/check-voice.mjs` та застарілу `docs/voice.md`.
- Додано `telegram/text.test.mjs`, оновлено інші тести, package.json, `.env`,
  `.env.example`, README та матеріали для здачі.

## Результати перевірок

- `npm test`: **63 тести пройдено**, 0 помилок, 0 пропущених; перед тестами `tsc`
  успішно створив збірку.
- Перевірено повний текстовий діалог: перше звернення → запит імені → `/input`
  → уточнення → явне підтвердження → фінальне зведення → припинення відповідей.
- Перевірено відхилення голосових/вкладень без AI і без завантаження файлів,
  продовження бронювання після такого вкладення та текстову відповідь на прохання аудіо.

  повторного `/book`, дублікатів, контексту, зупинки й маскування логів.
- Попередні успішні живі перевірки належать попереднім версіям. Нові API-прогони

текстовий сценарій додатково перевірено новими інтеграційними тестами.

## Наступна ручна перевірка

Перезапустити процес, ввести `/book` та відповідати з тестового акаунта лише
текстом. API 503 може траплятися незалежно від формату повідомлення; якщо обидві
моделі недоступні, контекст зберігається для повтору `/book`. Реальному менеджеру
повідомлень не надсилалося; повна нова переписка через Telegram ще не підтверджена.
