# Матеріали для здачі: текстове бронювання

## Вибір інструментів та використання AI

1. Збережено Node.js і TypeScript та наявну модульну архітектуру.
2. Teleproto використано для приватного листування з Telegram-акаунта.
3. Основна модель — Gemini 3.1 Flash-Lite за вибором власника проєкту.
4. Gemini 3.5 Flash-Lite налаштована резервною для тимчасових збоїв основної.
5. AI генерує природні англійські репліки з усієї історії, без готового сценарію.
6. Код перевіряє походження фактів, персональні дані та повноту фінального підтвердження.
7. Лог JSONL містить текст, відправника, коротке розуміння, рішення та стан.
8. AI використано для аналізу, правок і тестів; голосові свідомо вилучено за запитом власника.

## Проблеми, обмеження та невпевненість

Поточна версія підтримує лише текст: необов'язковий голосовий пункт завдання не
реалізовано. Раніше живі запуски виявили 503/504 від Gemini; резервна модель та
обмежені повтори зменшують вплив таких збоїв, але не гарантують доступності API.
Квоти конкретного проєкту не підтверджені. AI-перевірка фактів не є формальною
гарантією й додає затримку. Активна історія зберігається в RAM і втрачається після
перезапуску. У логах маскуються секрети й відомі персональні дані, але невідомі
імена можуть залишатися. Нову повністю текстову версію перевірено автоматичними
тестами з підмінами; повну реальну переписку після вилучення голосових ще не проведено.
