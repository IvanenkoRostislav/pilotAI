# TablePilot AI

Підтримка голосових повідомлень: [налаштування, моделі, тарифи та перевірки](docs/voice.md).

Автономний ШІ-агент для бронювання столиків у ресторані через Telegram.

Поточний етап: базовий Node.js + TypeScript проєкт. Інтеграції Telegram,
OpenAI API та логіку бронювання ще не реалізовано.

## Вимоги

- Node.js 24 або новіший.
- npm (постачається разом із Node.js).

## Початок роботи

```sh
npm ci
npm run dev
```

Команда розробки виводить `TablePilot AI successfully started.` і залишається
в режимі спостереження за змінами. Для зупинки натисніть `Ctrl+C`.

Змінні середовища наразі не потрібні. `.env.example` — заготовка для наступних
етапів; автоматичне завантаження `.env` поки не налаштовано. Секрети не слід
додавати до репозиторію.

## Команди

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Запуск TypeScript із перезапуском після змін |
| `npm run typecheck` | Перевірка типів без генерації файлів |
| `npm run build` | Компіляція TypeScript у `dist/` |
| `npm start` | Запуск зібраного проєкту |

Для перевірки збірки та запуску:

```sh
npm run typecheck
npm run build
npm start
```

Зібраний застосунок виводить повідомлення про успішний запуск і завершується.
Постійний процес агента буде додано на наступних етапах.

## Структура

```text
src/
  index.ts       # Точка входу
  config/        # Майбутня конфігурація застосунку
  modules/       # Майбутні функціональні модулі
```

Порожні директорії збережено через `.gitkeep`. Кожен майбутній функціональний
модуль матиме власну папку в `src/modules/`. Додаткові шари та абстракції
додаватимуться лише за потреби.

Проєкт використовує ES modules і строгий режим TypeScript. Для майбутніх
відносних імпортів між TypeScript-файлами використовуйте розширення `.js`,
щоб зібраний код коректно запускався в Node.js.
